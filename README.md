This Python project is intended to print amateur radio radiograms in mailable form.
It uses .m2s ("mail to send") files as generated by flmsg, from the fldigi suite.
Put a file named return_address.txt in the same directory as the Python code for the return address.
Run the program, use the dropdown menu to choose a .m2s file, and choose a name for the resulting .pdf.
That .pdf will best be used with double-side printing.  It may be folded into a mailing envelope dimension;
tape shut, attach a stamp, and drop in a mailbox for radiogram delivery.
